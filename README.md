# Tiroir – TP BDD et Git

Base de données MySQL de Tiroir, une appli de location d'objets entre particuliers.

- `regles.txt` : règles de gestion
- `mcd.png` : MCD
- `mld.txt` : MLD
- `01_schema.sql` : création de la base (tables, contraintes, triggers)
- `02_donnees.sql` : jeu d'essai
- `03_index.sql` : index des recherches fréquentes
- `04_migration.sql` : ajout de la commission
- `git.md` : partie Git

Exécuter les scripts dans l'ordre, de 01 à 04, sur MySQL 8.
